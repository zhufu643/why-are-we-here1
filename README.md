# Why Designers Should Understand Programming
Today, AI systems can generate executable code from just a few sentences and even help creators quickly build simple websites or games. This makes learning programming seem somewhat outdated, as if it were an activity left behind by the times. However, as a designer, I believe that learning programming remains essential. Programming should not merely be seen as a constantly evolving technology that could easily be replaced by new tools; rather, it should be understood as a language or medium—an important bridge for communicating with artificial intelligence. Understanding programming languages significantly affects our ability to clearly express our ideas to AI and ultimately determines how efficiently and actively we can use these powerful tools of the new era.

Throughout history, whenever new technologies have emerged, similar changes have taken place. With the development of typewriters, printing technologies, and computers, traditional scribes were gradually replaced by machines, but writers and language did not disappear. Text has always been a medium through which writers express their thoughts, and new technologies have only changed the way they work. Computers can help writers record, revise, and distribute text more quickly, but they cannot replace writers when it comes to deciding what they truly want to express. I believe that the relationship between designers and AI is similar today. AI can help us generate code, but designers still need to decide what to create, why to create it, and what effect the final work should have. Mastering programming is like mastering a language. Even though AI has changed the way we work and can “speak” or “organize” this language for us, we still need the ability to read and understand it in order to judge whether the results generated by AI accurately reflect our design intentions. After all, it is still the designer’s responsibility to determine what the work should express.

Dylan Beattie points out in The Art of Code that code is not merely a technical tool used to solve practical problems and improve efficiency. Through examples such as generative art, programming languages, and live coding, he demonstrates another way of understanding programming: some people write code not simply to complete a certain function, but to explore, express, and create through code, just as artists use pigments, sounds, or images. From this perspective, programming itself can also be regarded as a creative medium used to communicate and realize an artist’s ideas. Just as painters need to understand the characteristics of color, composition, and materials, code also becomes a kind of “material” that designers need to understand as digital systems increasingly become important environments for design and artistic creation. Future designers may not need to write all the code by hand, just as artists do not need to make their own canvases, paints, or brushes. However, this does not mean that designers can completely avoid understanding programming languages. Especially in today’s era, when AI can generate code rapidly, if a digital media designer is completely unable to read and understand AI-generated code, it becomes very difficult to determine whether the code truly achieves their design intentions or to identify possible logical problems and limitations. Canadian media theorist Marshall McLuhan proposed that media are “extensions of man.” Coding can also be understood as an extension of thought: it transforms abstract and vague ideas in the mind into rules that computers can understand and execute. Therefore, learning programming is not merely about learning how to write correct syntax. More importantly, it is about developing the ability to structure ideas. In the process of learning programming, designers constantly practice breaking down complex ideas into a series of clear instructions and logical relationships. In other words, programming trains not only technical skills, but also logical thinking, system design, and creative expression.

AI may change how we write code, but it does not make programming meaningless. For designers, coding is a way to understand digital systems and turn ideas into clear rules. AI can generate code for us, but we still need to decide what we want to create and why it matters.
